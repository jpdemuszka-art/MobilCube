# Google Ads Editor import

Generated by `python3 ads/build_import.py` from the keyword research (`ads/keywords/*.research.json`) and the ad copy in the script. Re-run the script after editing copy, prices or landing URLs; it refuses to write anything that breaks Google's character limits.

## Files, in import order

| File | Contents | Editor destination |
|---|---|---|
| `01-campaigns.csv` | 8 Search campaigns, paused, daily budgets, Maximize clicks with CPC cap | Campaigns |
| `02-ad-groups.csv` | Themed ad groups (Standard), default max CPC | Ad groups |
| `03-keywords.csv` | Phrase + exact keywords with launch bids and the segment landing URL | Keywords |
| `04-responsive-search-ads.csv` | One RSA per ad group, 15 headlines (positions 1–2 pinned), 4 descriptions, paths | Responsive search ads |
| `05-negative-keyword-lists.csv` | Shared lists `Negatives - FR` (171 terms) and `Negatives - EN` (98 terms) | Shared library → Negative keyword lists |
| `06-campaign-negatives.csv` | Campaign-level negatives (RVs, big boats, parking, insurance, job seekers, brand on non-brand campaigns) | Campaign negative keywords |
| `07-sitelinks.csv`, `08-callouts.csv`, `09-structured-snippets.csv` | Assets per campaign | Assets |

## How to import

1. Google Ads Editor → open the account → **Account › Import › From file…** (or paste from a spreadsheet).
2. Pick the CSV. In the mapping dialog, confirm each column matches the Editor field with the same name (headers here use Editor's names; `Criterion Type` values are `Exact`, `Phrase`, `Negative Exact`, `Negative Phrase`).
3. Review the proposed changes, fix any red rows, **Finish and review changes**, then **Post**.
4. In the web UI afterwards: attach the two shared negative lists to every campaign, set locations (see `docs/02-google-ads-strategy.md` §3), ad schedule, conversion goals, call asset with a forwarding number, location asset, price asset and image assets. Then un-pause.

## Before you post

- Replace `https://offres.mobilcube.com/...` with the real landing-page host if you deploy `landing/` elsewhere (change `LP_BASE` in `ads/build_import.py` and re-run).
- Prices in ads (350 $, 270 $, 289,75 $, 180 $, 300 $ delivery) must still match the booking platform on launch day.
- Two ad groups are intentionally **Paused**: `Bateau (test, pausé)` / `Boat (test, paused)` (most boat searches are for boats that do not fit a 20 ft unit) and `Self storage alternative (test, paused)` (expensive generic terms). Enable them only as experiments.
- Keyword volumes and CPCs behind the bids are estimates; do a Keyword Planner pass first.
